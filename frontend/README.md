# Frontend - LyftrAI Assignment

React + Vite frontend for the web scraping application.

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS v4** - Utility-first styling
- **shadcn/ui** - Component library (Button, Card, Tabs, Accordion)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The build output will be in the `dist/` directory, which is served by the FastAPI backend.
